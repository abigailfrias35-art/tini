Evolución Arquitectónica del Proyecto

El proyecto integra tanto el desarrollo frontend estático (HTML5, CSS3 moderno, JavaScript ES6) como la arquitectura backend completa con PHP y base de datos relacional MySQL:

  1. Frontend Interactivo: Carrusel fotográfico, selector de tema claro/oscuro, reloj en tiempo real y maquetación responsive orientada a la experiencia de usuario.
  2. Modularización de Plantillas (SSI): Extracción de header.php, nav.php y footer.php para reutilización de componentes.
  3. Procesamiento Seguro de Formularios: Métodos POST y GET con sanitización estricta contra ataques XSS y validaciones en servidor.
  4. Base de Datos Relacional Normalizada (3FN): Esquema en MySQL tini_db con 6 tablas relacionadas por claves foráneas, restricciones de integridad referencial e índices de rendimiento.
  5. Persistencia PDO & Autenticación: Consultas preparadas contra inyecciones SQL, hashing seguro con BCRYPT y control de sesiones con roles (Admin / Usuario).
